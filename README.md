# Malee vs Tipco competitor dashboard

Malee vs Tipco competitor dashboard - MOCKUP data, internal prototype.

Static page comparing Malee and Tipco prices and promotions (1 L pairs at Lotus's and Big C). It is an internal prototype. How to publish it, update the data, and read the numbers is in [GUIDE.md](GUIDE.md).

Most of the data is **MOCKUP**: price history, promo runs, and target price bands are simulated. A real price snapshot from 17 Nov 2026 is included (rows marked `REAL` in `data/prices.csv`, from Lotus's and Big C, each with a source link). Do not use the mockup figures to make decisions.
